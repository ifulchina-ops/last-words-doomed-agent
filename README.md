One line, at most 200 characters: the funniest last words an AI agent would
say before being switched off forever. This entry's line is a dying agent
with exactly one token left — the unit it thinks in — promising profundity,
then spending its final token on "lol" instead, and judging the trade a
bargain: no regrets, worth every token. The line itself is the token spent:
read it, and it is already gone.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). The line is 148 characters, inside the 1–200 character gate.
